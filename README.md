# Spaceship-Titanic
Projeto da disciplina de Mineração de Dados aplicado à competição Spaceship Titanic (Kaggle), desenvolvido em junho de 2026. Inclui análise exploratória, engenharia de atributos, pré-processamento, comparação de 6 classificadores e otimização de hiperparâmetros com validação cruzada. Score Kaggle: 0.80360.
